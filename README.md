# my_Dev_Log

A lightweight GitHub Pages site for tracking personal projects, current work, and future ideas.

## Files

- `index.html` — the main site structure and placeholder content
- `styles.css` — the responsive visual design
- `script.js` — the theme toggle behavior

## Publish on GitHub Pages

1. Push the site files to your repository.
2. In GitHub, open **Settings > Pages**.
3. Set the source to **Deploy from a branch**.
4. Choose your main branch and the repository root (`/`).
5. Save, then wait for GitHub Pages to publish the site.

After that, replace the placeholder text with your real project updates.
